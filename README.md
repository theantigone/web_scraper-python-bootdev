# [Build a Web Scraper in Python](https://www.boot.dev/courses/build-web-scraper-python)

# prerequisites

- python 3.10+
- uv

# getting started

1. install the dependencies for this web crawler:

```sh
uv sync # recommended
```

2. alternatively, you can use the `pip` equivalent:

```sh
uv pip install -r requirements.txt
```
